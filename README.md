# ipTIME 원격 WOL 프로그램

외부 인터넷에서 집 안의 ipTIME 공유기(`your-ddns.iptime.org:원격포트`)에 접속하여 특정 PC를 원격으로 켜는 프로그램입니다.  
공유기 관리자 페이지의 WOL 기능 동작 방식을 역공학(Reverse Engineering)하여, 무겁고 복잡한 관리자 페이지 대신 **WOL 기능만 빠르고 가볍게 실행**하도록 제작되었습니다.

---

## 📁 파일 구성

| 파일명 | 설명 |
| :--- | :--- |
| **`WOL_실행.bat`** | 더블 클릭하면 GUI 실행기가 바로 열리는 윈도우 실행 파일 |
| **`launch.vbs`** | 콘솔 창 없이 GUI 실행기만 깔끔하게 띄우는 실행 파일 |
| **`gui.py`** | 그래픽 화면(GUI) 기반 WOL 컨트롤러 (DHCP/ARP 기기 탐색, 별칭 설정, 원클릭 부팅) |
| **`iptime_wol.py`** | 공유기 로그인, WOL/DHCP/접속 목록 조회, 자동 등록 및 WOL 송출 핵심 모듈 |
| **`lan_scanner.py`** | 내부망(LAN) ARP 스캔으로 주변 기기 IP/MAC/호스트명을 탐색하는 모듈 |
| **`quick_wake.py`** | 저장된 설정으로 0.5초 만에 PC를 바로 켜는 백그라운드/CLI 스크립트 |
| **`config.json`** | 공유기 주소, 포트, 계정 정보, 대상 MAC 및 기기 별칭(`aliases`) 저장 파일 |

## ⚙️ 1. ipTIME 공유기 사전 필수 설정

프로그램이 공유기에 정상 접근할 수 있도록 공유기 설정 페이지(`http://192.168.0.1` 또는 `http://your-ddns.iptime.org:원격포트`)에서 아래 3가지를 확인해주세요.

1. **원격 관리 포트 활성화**
   - 메뉴: `고급 설정` → `보안 기능` → `공유기 접속/보안관리`
   - **[원격 관리 포트 사용]** 체크 후 원하는 포트 번호(예: `8080` 또는 5자리 난수 포트 권장) 입력 및 적용
2. **로그인 보안문자(CAPTCHA) 끄기** (필수)
   - 메뉴: `고급 설정` → `보안 기능` → `공유기 접속/보안관리`
   - **[로그인 시 보안문자 사용 안 함]** 선택 및 적용
   - *(보안문자가 켜져 있으면 자동 로그인이 차단됩니다.)*
3. **WOL PC 등록**
   - 메뉴: `고급 설정` → `특수 기능` → `WOL 기능`
   - 켜고 싶은 PC를 등록 (현재 켜져 있는 상태에서 [현재 접속된 PC의 MAC 주소로 설정] 클릭 후 등록)

## 💻 2. 프로그램 사용 방법

### 방법 A. 간편 GUI 화면 사용 (추천)
1. 바탕 화면의 [**`WOL_실행.bat`**](WOL_실행.bat) 또는 [**`launch.vbs`**](launch.vbs)를 더블 클릭합니다.
2. 공유기 주소(예: `your-ddns.iptime.org` 또는 `192.168.0.1`), 원격 포트, 아이디, 관리자 비밀번호를 입력합니다.
3. **[🌐 공유기 조회 (WOL + DHCP/접속기기)]** 버튼을 누르면 공유기 WOL 등록 목록뿐만 아니라 DHCP 할당 현황, 접속 기기 목록까지 한 번에 가져옵니다.
4. 집 안(내부망)에 있다면 **[🔍 내부망 ARP 스캔]**으로 현재 네트워크에 연결된 기기들의 IP/MAC/호스트명을 바로 찾을 수 있습니다.
5. 목록에서 기기를 클릭하고 아래 **기기 이름 (별칭)** 칸에 원하는 이름(예: `내 데스크톱`)을 적어 **[이름 저장]**을 누르면 [`config.json`](config.json)에 저장되어 다음에도 쉽게 알아볼 수 있습니다.
6. **[⚡ 지금 PC 켜기 (WOL 실행)]** 버튼을 누르면 끝! (*"미등록 기기일 경우 공유기에 자동 등록 후 부팅"* 옵션이 켜져 있으면 공유기에 등록되지 않은 기기도 자동으로 등록 후 켜줍니다.)

### 방법 B. 원클릭 즉시 실행 (`quick_wake.py`)
`gui.py`에서 설정을 한 번 저장해 두면, 이후에는 단축키나 배치 파일 하나로 바로 실행할 수 있습니다.
```bash
python quick_wake.py
```

## 🔍 3. 동작 원리

이 프로그램은 아래와 같은 HTTP 통신 과정을 자동으로 처리합니다:

1. **세션 획득 및 인증 (`login_session.cgi` → `login_handler.cgi`)**
   - 브라우저처럼 위장한 HTTP Header(`User-Agent`, `Referer`, `Host`)를 구성하여 관리자 계정 POST 요청
   - 로그인 성공 시 발급되는 세션 식별 쿠키(`efm_session_id`) 저장
2. **WOL 패킷 송출 (`timepro.cgi`)**
   - 세션 쿠키를 동봉하여 `tmenu=iframe&smenu=expertconfwollist&act=wake&wakeupchk=<MAC>` 요청 전송
   - 공유기 내부 리눅스 커널이 해당 MAC 주소로 브로드캐스트 매직 패킷(Magic Packet)을 송출
